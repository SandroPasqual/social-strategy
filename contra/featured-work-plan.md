## Proiectul 3 — The Diagnosis Process

**Tip:** Metodologie
**Format:** Imagine — diagramă vizuală
**Status:** De construit

### Conținut

**Titlu:** The Diagnosis Process — From Questionnaire to Report

**Cover image:** O diagramă vizuală simplă (4 pași, conectați):

```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│  Questionnaire │ ──→ │   Discovery   │ ──→ │  Independent  │ ──→ │  Perception  │
│   (written)   │     │   Session    │     │   Research   │     │  Gap Report  │
│               │     │   (60 min)   │     │              │     │  (7 days)    │
└──────────────┘     └──────────────┘     └──────────────┘     └──────────────┘
```

**Descriere:**

> Procesul în 4 pași care produce un Perception Gap Report. Nu începe cu design, nu începe cu un brief — începe cu un questionnaire scris, structurat, pe care clientul îl completează în ritmul lui.
>
> Urmează o sesiune de descoperire de 60 de minute — focusată, fără small talk. Apoi cercetare independentă. Apoi raportul.
>
> Totul durează 7 zile. Rezultatul e un diagnostic complet, nu o mostră ca să vinzi ceva mai mare.

### Ce imagine

O diagramă simplă, minimalistă — 4 casete conectate cu săgeți. Fundal închis, text deschis, linii subțiri. Același stil ca restul.
